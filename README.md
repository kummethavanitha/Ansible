****ANSIBLE****
Ansible is a open soruce tool which is used to install softwares, configuration management and automate the tasks in multiple servers.

**Configuration Management**
it is process of managing systems in a consistent state and desired state it involves managing the configurtaion files and services and sofware installation on mutliple servers 

**Ansible is Agentless**
ansible is agentless because ansible is downaloaded in only devolopers machine no need to run in all servers
